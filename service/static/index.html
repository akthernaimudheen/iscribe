STT Privacy Boundary

Audio is sent to the configured speech-to-text provider only when the provider's declared processing location and zero-retention configuration satisfy the hospital's active STT policy. Automatic fallback is disabled when fail-closed mode is enabled. This panel shows configuration facts only — it makes no compliance or deletion guarantees.
